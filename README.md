# AdFree Player

A lightweight Android app (Android 7.0+) that opens the YouTube mobile website in a clean full-screen
WebView and skips video ads.

## Download
Go to the **Releases** page and download `AdFreePlayer.apk`. Install it, allow
"Install unknown apps" for your browser/file manager if Android asks.

[Download APK](https://github.com/itzharsh01126/ad-free-player/releases/download/v1.0/AdFreePlayer.apk)

## Disclaimer
- This is an **unofficial** app. It is **not affiliated with, endorsed by or sponsored by YouTube or Google**.
  YouTube is a trademark of Google LLC.
- Blocking ads may go against YouTube's Terms of Service. **Use at your own risk.**
- The app does not collect, store or send any personal data. It never reads or saves your passwords.
  Sign-in (if you choose to) happens on Google's own pages.
- Only install the APK from this repository's **Releases** page. Do not install copies from anywhere else.

## Build
GitHub Actions builds and signs the APK automatically (see `.github/workflows/build.yml`).
Create a release with a tag like `v1.0` and the signed APK is attached to it.
